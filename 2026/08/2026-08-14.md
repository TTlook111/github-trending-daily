Macro 是一个"团队操作系统"——将邮件、即时消息、文档、任务、AI Agent、通话和 CRM 统一在一个界面中，通过 @-link 双向图将所有实体关联起来，并共享团队级 AI 记忆。它要解决的核心问题是：创业公司使用 Slack + Linear + Notion + HubSpot + Superhuman 等多个工具，这些工具之间无法作为一个系统协同工作。Macro 用 SolidJS + Rust 从头构建了一个所有模块共享同一个后端的统一平台，Agent 作为一等公民参与 CRDT 协作编辑。

💡 可借鉴的优点

- **工程化**：Rust 后端 + SolidJS 前端 + CRDT 协作，技术选型兼顾性能和实时性
- **产品思维**：Agent 可以像人类一样作为 CRDT 协作者编辑文档，这是"AI native"协作的正确打开方式
- **代码质量**：近 5,000 commits，支持 Nix 构建、Docker 部署、全平台覆盖

🌟 特别亮眼的地方

"The company was not computable" 这个洞察极其精准。Macro 的独特价值不在于某个模块做得多好，而在于将所有工作上下文连成一张可计算的图——这意味着 AI Agent 能理解你整个公司的运作，而不只是某个孤立的工具。

| 属性 | 信息 |

| 📦 分类 | AI / 金融量化 / 时序预测 |

📖 项目是干什么的

Kronos 是首个开源的金融 K 线（蜡烛图）基础模型，在全球 45+ 交易所数据上预训练。它采用创新的两阶段框架：先用专用分词器将连续的 OHLCV 多维 K 线数据量化为层次化离散 token，再用大型自回归 Transformer 在这些 token 上预训练，从而统一处理多种量化任务。模型家族从 4.1M（mini）到 499.2M（large）参数，支持批量预测、自定义微调（含 A 股 Qlib 示例），并被 AAAI 2026 接收。

💡 可借鉴的优点

- **架构设计**：将 K 线数据类比为"语言"进行 tokenize 的思路新颖——OHLCV 五维数据的层次化量化是核心创新
- **工程化**：完整的从推理到微调到回测的 pipeline，支持多 GPU torchrun 分布式训练
- **代码质量**：提供详细的 API 示例（单条/批量预测）、完整的 Qlib 微调流程和回测脚本
- **学术价值**：AAAI 2026 论文背书，同时兼顾学术严谨性和工程可用性

🌟 特别亮眼的地方

"金融市场的语言模型"这个定位本身就极具想象力。不同于通用时序预测模型，Kronos 专门针对金融数据的高噪声特性设计，用 token 化方法将连续数值问题转化为序列建模问题。对量化开发者来说，这是一个开箱即用的 alpha 信号生成器基座。

| Agent 并行编排 | Orca | 让开发者同时管理多个 Agent |
| Agent 组织管理 | Paperclip | 让 Agent 像员工一样被组织化管理 |
| Agent 决策审计 | Semantica | 让 Agent 的决策可追溯可审计 |
| Agent 统一工作台 | Macro | 让 Agent 和人在同一个系统中协作 |

这反映了一个清晰的行业演进路径：**单 Agent → 多 Agent 并行 → Agent 组织化 → Agent 治理与合规**。

### 升温领域

1. **Agent 治理与合规**（Semantica）：随着 AI 进入高风险决策领域，"AI 做了什么、为什么"将成为监管硬性要求
2. **原生办公文档生成**（PPT Master）：AI 输出质量正在从"能用"进化到"专业级原生"
3. **金融 AI 基座模型**（Kronos）：垂直领域基础模型持续涌现，K 线 token 化是一个优雅的范式
4. **全栈工作平台**（Macro）：工具碎片化催生了"一个系统统治一切"的需求

### 对开发者的启发

- **如果你在做 Agent 产品**：不要只关注 Agent 能力，治理、审计、组织管理才是企业买单的理由
- **如果你在做办公自动化**：输出"原生格式"（不是截图/图片）将成为竞争的基本门槛
- **如果你在做 AI 基础设施**：知识图谱 + 确定性推理 + 溯源的组合正在获得越来越多关注
- **如果你是独立开发者**：像 diagram-design 这样的"AI 插件/技能"赛道正在爆发，小而精的插件同样能获得万星级认可
