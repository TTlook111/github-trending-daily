## 总览摘要

今日 GitHub Trending 呈现出一个鲜明的主题：**AI Agent 从"通用对话"向"专业技能"全面转型**。榜单前三名——Archify（架构图技能）、God's Eye View（空间情报可视化）、Scientific Agent Skills（科学研究技能库）——分别代表了 Agent 在工程可视化、地理空间情报和科学研究三个垂直领域的深度落地。这不再是"让大模型更聪明"的通用能力竞赛，而是"让 Agent 在特定岗位上独当一面"的专业化浪潮。

值得关注的是，**开源空间情报**（OSINT）成为今日的隐藏主线：God's Eye View 把卫星模拟器搬进浏览器，user-scanner 提供 455+ 扫描向量的邮箱/用户名情报提取，二者分别从宏观（全球态势感知）和微观（个体数字足迹）两个维度展示了开源情报工具的爆发力。这反映出开发者社区对"信息透明化"和"公共数据可视化"的持续高涨热情。

第三个趋势是 **Agent Skills 标准的生态扩张**。Archify、Scientific Agent Skills、awesome-claude-skills 等项目都在围绕 `npx skills add` 和 Agent Skills 标准构建可组合的技能生态。这意味着 AI Agent 的能力将不再依赖单一模型的"涌现"，而是像 npm 包一样被安装、组合和复用。对于开发者而言，**写一个好的 Agent Skill 可能比写一个好的 npm 包更有商业价值**。

| 属性 | 信息 |

| 💻 语言 | JavaScript |
| 📦 分类 | AI Agent 技能 / 架构可视化 |

📖 项目是干什么的

Archify 是一个面向 AI Agent 的架构图渲染和验证系统。它让 Cursor、Claude Code、Codex CLI 等编码代理可以直接在对话中生成交互式的系统架构图、工作流图、序列图、数据流图和生命周期图。Agent 产出结构化的 JSON IR（中间表示），Archify 确定性地将其编译为自包含的 HTML/SVG 文件，支持动画、暗/亮主题切换、PNG/SVG/WebM 导出，以及 1200×630 的社交分享卡片。

最令人印象深刻的是其"架构 Delta 对比"功能——可以比较两个验证过的架构快照，精确标注新增、删除、变更、移动和重路由的组件，让 PR Review 中的架构变更一目了然。

💡 可借鉴的优点

- **产品思维**：将"架构图"这个高频但低效的工作流（通常需要 Figma/Draw.io + 反复调整）缩短为"一句话描述 → 交互式产物"。产品定位精准，切入的是开发者每天都在做但又懒得做好的事。
- **架构设计**：采用 JSON IR 中间表示 + 确定性编译的双层架构，将"AI 生成"和"渲染验证"解耦。这意味着即使 AI 生成的内容有误，验证层也能捕获并提供修复建议（repair receipt），而不是像 Mermaid 那样直接渲染错误结果。
- **工程化**：原子级验证——schema、layout、HTML/SVG、route、label-to-route 五重检查全部通过才交付。失败时返回结构化的修复收据（stable rule codes + exact subject + measured evidence），而不是 Node 栈或非结构化重试猜测。
- **社区运营**：提供 Proof Lab（11 个已检入场景的交互演示）、场景指南、零依赖 CLI 引导，让用户在安装前就能体验产品。赞助商模式也很聪明——APINEBULA 和 EverMind 的赞助直接绑定到产品功能。

🌟 特别亮眼的地方

Archify 的核心创新在于"**可信交互**"（Truthful Interaction）。它的聚焦、上下游追踪、精确路由、角色对比和引导式故事都复用已验证的节点和关系，**从不凭空发明拓扑结构或声称运行时影响**。这在 AI 生成内容普遍存在"幻觉"问题的今天，是一个非常重要的工程决策。它本质上是在说：**Agent 生成的图不是"近似正确"，而是"可验证正确"**。

| 属性 | 信息 |

📖 项目是干什么的

God's Eye View 是一个运行在浏览器中的"间谍卫星模拟器"——但数据是真实的。它在一个逼真的 3D 地球上实时展示飞机（ADS-B 转发器）、船舶（AIS 信标）、卫星（轨道根数）、地震、交通流量和公共摄像头数据。用户可以锁定追踪任何目标、进入驾驶舱视角、切换传感器模式（CRT/夜视/热成像/红外），甚至通过语音与 AI Agent 交互来控制整个场景。

核心卖点是所有数据都来自公开源：航班遥测、船舶信标、ISS 轨道数据、公共摄像头。项目的前身是 YouTube 上播放量 500 万+ 的 God's Eye View 系列视频。

💡 可借鉴的优点

- **产品思维**：把"散落在各个浏览器标签页中的公开情报数据"整合为一个统一的、沉浸式的 3D 体验。项目描述中的那句话精辟——"信号是丰富的，接口才是瓶颈"。这本质上是一个"数据聚合 + 极致可视化"的产品。
- **架构设计**：每个数据层都明确标注了数据源和新鲜度状态（包括 partial、delayed、simulated、unavailable），对模拟数据明确标记为"RECONSTRUCTED ESTIMATE"。这种对数据诚实度的极致追求在情报工具中至关重要。
- **工程化**：冷启动在现代笔记本上不到 2 秒，开发服务器绑定 localhost（API 密钥不外泄），macOS 快捷脚本从 Keychain 拉取密钥。成本控制也做到极致——Google Maps 3D 免费额度足够个人使用，语音内置 $5 会话上限。
- **社区运营**：从 YouTube 500 万播放量的视频系列到开源，天然自带流量。README 的"前五分钟体验"叙事设计堪称教科书——从点亮天空到驾驶舱到公共摄像头到轨道追踪，层层递进的沉浸感。

🌟 特别亮眼的地方

项目最令人惊叹的设计是**"看起来像禁区驾驶舱，但每一行代码都可审查"**。它精准地把握了人类对"全知视角"的好奇心——这种好奇心驱动了无数间谍电影和军事模拟游戏，但 God's Eye View 用公开数据和开源代码把它变成了现实。从社区到产品的转化路径（YouTube → 开源）也是一个值得学习的增长策略。

📖 项目是干什么的

Scientific Agent Skills（原 Claude Scientific Skills）是一个包含 163 个即用型科学研究技能的集合，覆盖生物信息学、化学信息学、蛋白质组学、临床研究、材料科学、物理天文、地球科学等 19 个科学领域，整合了 100+ 个科学和金融数据库（PubChem、ChEMBL、UniProt、COSMIC、ClinicalTrials.gov 等）。

它遵循开放的 Agent Skills 标准，兼容 Cursor、Claude Code、Codex、Google Antigravity 等主流 AI 编码代理。配套的 K-Dense BYOK 是一个免费的开源 AI 共同科学家桌面应用，支持 40+ 模型和本地运行。项目已被 19 万+ 科学家使用。

💡 可借鉴的优点

- **产品思维**：不是做一个"AI 科学家"产品，而是把科学研究的能力拆解为可组合的"技能"。163 个技能 × 100+ 数据库的组合爆炸，让每个科学家都能根据自己的研究方向组装专属的 AI 助手。"技能市场"思维比"万能产品"思维更具可扩展性。
- **架构设计**：整个仓库同时是 Agent Skills 标准的技能包和 Agent Plugins 标准的插件包（plugin.json + skills/），一套代码适配两种分发标准。数据库访问层提供"确定性、可溯源"的统一接口，而不是让 Agent 自由爬取。
- **工程化**：每个技能都提供策展的文档和示例，而非简单的 API wrapper。技能涵盖从基础操作（序列分析）到复杂工作流（端到端论文复现）的完整梯度。视频教程从"技能 101"到"复现 Nature Medicine 论文"，学习路径清晰。
- **社区运营**：从"Claude Scientific Skills"更名为"Scientific Agent Skills"是一步精妙的品牌策略——脱离单一平台绑定，拥抱标准化生态。19 万+ 科学家的用户基础是强大的护城河。

🌟 特别亮眼的地方

这个项目展示了 **Agent Skills 标准在垂直领域的真正威力**。当一个领域的专业知识被拆解为可安装、可组合、可复用的技能包时，AI Agent 的能力边界就不再取决于基础模型的参数量，而取决于技能生态的丰富度。对于科学研究这样高度专业化且工具碎片化的领域，这种"技能化"路径可能比训练专用科学大模型更实际、更可信。

🌟 特别亮眼的地方

## 📊 今日趋势洞察

### 核心方向：Agent Skills 生态的"寒武纪大爆发"

今日 Top 10 中至少有 4 个项目直接与 Agent Skills 标准相关（Archify、Scientific Agent Skills、OpenMontage、awesome-claude-skills），另有 2 个项目间接服务于 Agent 生态（go-modern-guidelines 指导 Agent 写 Go，OpenMAIC 用多 Agent 做教育）。这意味着 **Agent Skills 正在从"编程辅助的附加功能"进化为"独立的软件分发范式"**。

就像 npm 生态催生了一整代 JavaScript 工具链公司，Agent Skills 生态可能催生一整代"AI 能力供应商"。不同的是，Agent Skills 的颗粒度更粗（一个 Skill 可能包含数百个文件和复杂的工作流），但商业价值也更高——因为它封装的不仅是代码，还有领域知识。

### 升温领域

1. **开源空间情报 OSINT**（God's Eye View、user-scanner）：公共数据的可视化和情报化正在成为一个独立赛道。God's Eye View 的 YouTube → 开源路径和 user-scanner 的 455+ 扫描向量都说明这个领域既有用户需求又有技术深度。
2. **AI 视频制作**（OpenMontage）：54K Stars 的开源视频制作系统，700+ Agent 技能文件。视频制作的"技能化"可能比图片生成的"提示化"更具革命性，因为视频制作涉及更长的工作流和更多的专业判断。
3. **AI 辅助编码的"元层"**（go-modern-guidelines、Archify）：不是 AI 写代码，而是"指导 AI 怎么写代码"和"验证 AI 写的代码"。JetBrains 和 Archify 分别从规范和可视化两个角度切入这个"元层"。
4. **轻量级网络工具**（tailcat）：Tailscale 继续证明"把复杂网络概念做简单"的商业模式。tailcat 可能成为 Agent 间安全通信的基础设施。

### 对开发者的启发

- **如果你在做 AI Agent 相关产品**：现在是投入 Agent Skills 生态的最佳时机。选一个你最擅长的垂直领域，把你的专业知识封装成可安装的 Skill。Archify 和 Scientific Agent Skills 的成功说明，好的 Skill 不是简单的 API wrapper，而是包含领域判断、验证逻辑和最佳实践的"知识胶囊"。
- **如果你在做开发工具**：注意 JetBrains 的信号——未来的编码规范和最佳实践需要同时面向人类和 AI。你的 linter、formatter、code review 工具可能需要一个"Agent 模式"。
- **如果你在做数据可视化**：God's Eye View 展示了"公共数据 + 3D 渲染 + AI 交互"三位一体的新范式。关键洞察是"信号已经存在，接口才是瓶颈"——找到那些数据丰富但可视化匮乏的领域，你就找到了产品机会。
- **如果你在做 SaaS 产品**：open-seo 再次证明，定价过高的 SaaS 终将面临开源替代。与其等别人来替代你，不如主动开源核心功能、在增值服务上盈利。
