📖 项目是干什么的

i-have-adhd 是一个为编码代理设计的"行为约束技能"，目标只有一个：**让代理别废话，直接给答案**。它用一组精炼规则重塑代理的输出风格——动作优先、步骤编号、结尾给出下一步、压制跑题、不要开场白也不要"Hope this helps!"。

整个项目的核心就是一份 SKILL.md 里的规则集，一行指令即可集成到 Claude Code 等插件系统，纯粹用"提示工程"解决体验问题，无需模型训练。

💡 可借鉴的优点

- **产品思维**：精准命中 LLM 输出最大痛点——信息密度低、关键信息被废话淹没。用"约束"而非"增加能力"来提升体验
- **架构设计**：极度轻量——核心就是一个 Markdown 规则文件，零复杂依赖，体现了 Agent Skills 的可组合性
- **社区运营**：MIT 许可 + 低门槛安装 + 高共鸣文案，天然易传播

🌟 特别亮眼的地方

它最大的启示不在技术而在认知：当所有人都在给代理"加能力"时，最实用的技能反而是"教代理少说话"。👉 遇到"如何让 LLM/代理输出更简洁可用"的问题时，直接抄它的规则清单是性价比最高的做法。
