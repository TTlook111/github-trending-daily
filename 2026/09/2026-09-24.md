📖 项目是干什么的

AX 是 Google 开源的声明式 Agent 编排运行时，核心比喻依然准确：**像 Kubernetes 管理容器一样管理 AI 代理工作负载**。它跑在 Agent Substrate（今日 #5）之上做沙箱化执行，目标是在单集群里跑数十亿个自主代理任务。用户用 `ax.io/v1alpha1` 的 YAML 声明任务，`ax apply -f task.yaml` 提交，整套操作和 kubectl 同构。

四个原语覆盖代理运行的全部要害：**Task** 把不可信代理代码关进带 CPU/内存限制的隔离沙箱；**Workspace** 预装 Git 仓库、MCP 服务器、技能包，让代理暖启动；**Gateway** 把出站流量锁在显式主机白名单；**Model** 声明平台自用的 LLM，凭证从 Kubernetes Secret 注入。另有 `ax suspend`/`ax resume`（暂停空闲代理、断点精确恢复）和 `ax ssh`（钻进运行中的沙箱观察）。技术上是 Go 编写、gRPC 通信、Redis 存状态、ko 构建、Apache 2.0 的标准云原生项目。

值得注意的是它的增长曲线：star 数从前天的 7,677 涨到今天的 9,128，两天新增近 1,500，且连续两天位居日榜前列。README 仍保留"稳定版前会有破坏性变更"的警告，说明项目在快速演进的同时，已经靠范式本身赢得了早期采纳。

💡 可借鉴的优点

- **产品思维**：精准抓住代理作为"新型工作负载"的本质——会累积状态、会调模型 API、没人看着能一直烧钱；四个原语正好对应隔离、预热、网络围栏、模型管控四个真实风险
- **架构设计**：全面复用 Kubernetes 十年沉淀的用户心智（声明式、apply/get/watch、多文档 YAML、跟随 kube-context），零学习成本，比自创 DSL 高明
- **工程化**：`debug: true` 才开放 ssh、凭证只走 Secret、网络默认拒绝，secure by default 贯穿始终；demo.sh 一键演示完整生命周期
- **文档体验**：按"概念/清单/沙箱/运行器/网络/架构"分表组织，每张表写明"读它能解决什么"

🌟 特别亮眼的地方

AX 连续两天霸榜且增速稳定，强化了一个判断：市场在等待"Agent 时代的编排标准"，而 Google 用它最擅长的 Kubernetes 范式给出了候选。对做 Agent 平台的人来说，它的原语划分（任务/工作区/网关/模型）几乎可以直接当作架构 checklist。

📖 项目是干什么的

Univer 是开源的全栈同构 Office SDK，让你在自己产品里构建表格、文档、幻灯片，而不被绑定到托管应用或固定 UI。它是"搭建生产力界面的框架"，而非文件查看器：插件化架构、Canvas 渲染、自研公式引擎，以及浏览器和 Node.js 通用的 Facade API。

三条集成路径兼顾速度与控制：**Preset 模式**用策划插件包几行代码跑出应用；**Plugin 模式**手动组合、控制注册顺序与包体积；**Headless 模式**在 Node.js 里无 UI 跑工作簿和文档逻辑——这是它作为"AI 基础设施"的关键，代理和服务端工作流可直接调用办公能力。开源核心中表格最成熟（公式、数据验证、条件格式、筛选排序、批注等），文档次之，幻灯片开发中；视图层 React 18，兼容 Vue、Web Components。实时协作、导入导出、打印、图表、透视表放在 Univer Pro。

今天最醒目的变化是增速：日增从昨天的 +255 跳升到 +1,142，star 总数一天内从 15,495 涨到 16,361。在整个榜单里，它是今日"加速度"最大的项目之一，说明"代理可调用的办公运行时"这个定位正在被市场快速理解。

💡 可借鉴的优点

- **产品思维**：明确"我提供搭积木的 SDK、不替你做成品"，聚焦嵌入场景（SaaS、内部工具、BI、AI 应用），边界清晰
- **架构设计**：同构是核心——浏览器交互与 Node.js 无头处理共用一套架构，一份能力两处复用；插件优先，功能可增删、替换、懒加载

🌟 特别亮眼的地方

📖 项目是干什么的

video-use 是 Browser Use 团队开源的视频剪辑技能：把原始素材丢进文件夹，和 Claude Code（也支持 Codex 等任何有 shell 权限的代理）对话，拿回 final.mp4，100% 开源，不依赖预设模板，对口播、混剪、教程、旅行、访谈等任何内容类型适用。

功能覆盖完整后期流水线：剪掉填充词（umm、uh、失败开头）与镜头间死区、逐片段自动调色（暖调电影感、中性锐利或任意自定义 ffmpeg 链）、每个切点 30ms 音频淡入淡出杜绝爆音、按风格烧录字幕（默认两词一组大写块）、通过 HyperFrames/Remotion/Manim/PIL 生成动画叠加（每个动画派一个并行子代理）、展示前对渲染输出逐切点自我评估，并用 project.md 持久化会话记忆。

核心设计是**LLM 从不"看"视频、而是"读"视频**：第一层用 ElevenLabs Scribe 做词级时间戳、说话人分离和音频事件，打包成约 12KB 的 takes_packed.md 作为主视图；第二层按需生成"胶片条 + 波形 + 词标签"PNG，只在决策点调用。对比朴素做法"3 万帧 × 1,500 token = 4,500 万 token 噪音"，它只要 12KB 文本加几张 PNG——与 browser-use 给 LLM 结构化 DOM 而非截图同理。今日 +746、排名从昨天的第 7 升到第 3，是榜单上爬升最快的项目之一。

💡 可借鉴的优点

- **产品思维**：把"素材变成片"用对话完成，产出目录（edit/）与技能目录分离，用户资产边界清晰
- **架构设计**："转写→打包→推理→EDL→渲染→自评"流水线，把语言推理与确定性 ffmpeg 工程干净分层；自评发现问题自动修复重渲（最多 3 次）
- **工程化**：安装提示让代理读 install.md 自行完成克隆、ffmpeg 装配、技能注册，只在需要 ElevenLabs key 时打断用户一次；12 条硬规则保证生产正确性，其余给艺术自由
- **生态站位**：依托 Browser Use Cloud/Box 提供常驻剪辑与 Telegram 入口，开源技能与托管服务互补

🌟 特别亮眼的地方

video-use 今天的爬升说明"让代理做视频"的需求比预想更广。它最有价值的方法论——构造低成本、高信息密度的文本主视图，再辅以按需视觉快照，而非硬塞海量帧——可以推广到一切时序媒体，是"LLM 如何理解非文本媒介"的范本。

📖 项目是干什么的

Agent Substrate 是安全默认的代理执行运行时，目标是跑上百万沙箱、密度做到标准容器运行时的 10 倍。核心洞察是**代理类应用绝大多数时间空闲**，于是把一大批 actor 映射复用到少量 worker 上，需要时快速唤醒。官方演示里约 250 个有状态 actor 复用到仅 8 个物理 Pod，超卖比超 30 倍。

性能围绕"快速休眠唤醒"：恢复低于 500ms，每秒 500+ 次挂起/恢复，通过全状态快照（RAM + 文件系统）完整保留工作记忆；隔离采用原生零信任内核与网络隔离，支持 microVM 和 gVisor 并对所有沙箱提供一致生命周期。它构建在 Kubernetes 之上（复用 Pod 与自动扩缩），自己只做代理专用调度，且保持"低主见"——任何 OCI 容器都能跑，兼容 ADK、LangChain、Claude Code、Codex、MCP。google/ax（今日 #1）建在它之上，CNCF 沙箱项目 kagent 也在使用。Go 编写、Apache 2.0，处于早期。

两天内 star 从 2,998 涨到 3,515（+558 今日），与上层 AX 形成同步增长的"上下层双热"，这种配套项目一起被采纳的现象在 Trending 上并不多见。

💡 可借鉴的优点

- **产品思维**：把"代理很闲却占机器"的浪费变成密度与成本优势，30 倍超卖对大规模部署是实打实的省钱
- **架构设计**：actor/worker 映射、全状态快照、按需唤醒，把"进程休眠"做到集群调度层；地基完全复用 Kubernetes，不另起炉灶
- **工程化**：Counter、Sandbox、Claude Code Multiplex、请求停泊（worker 占满时挂起请求而非返回 503）、自动扩缩等六个 Demo，每个设计点都可复现验证
- **生态站位**：框架与 harness 无关、内核层管理标准 OCI 容器，不绑定任何代理生态，反成公共执行层

🌟 特别亮眼的地方

Substrate 与 AX 组成今天最完整的"Agent 云原生"叙事：一个管调度密度、一个管声明编排，都出自 Google、都复用 Kubernetes、还同步增长。它提醒行业：代理规模化时真正的瓶颈不是模型智商，而是机器密度、唤醒延迟与隔离成本——这是云厂商才有的降维视角。

v3 分支合并后带来破坏性变更，命令重新分层：`mvt-ios`、`mvt-android` 分析平台提取物，`mvt` 主命令承载版本、补全、插件、IOC 下载；插件包可扩展取证模块与顶层命令。pip 或 uv 一条命令安装，支持 Bash/Zsh/Fish 补全。README 保持诚实：它是面向技术人员的研究工具、非普通用户自检用；仅靠公开 IOC 无法证明设备"干净"，可靠结论需非公开情报，可通过大赦国际或 Access Now 通道获取。自定义许可证旨在防止滥用侵犯非自愿者隐私。

这是它连续第三天在榜，且今日 +543 高于前两天（+177、+441），热度不降反升。

💡 可借鉴的优点

- **架构设计**：v3 把平台相关命令与通用命令分层、能力扩展做成插件，架构更可维护
- **工程化**：uv 工具化安装、补全仅在显式 `--install` 时写配置、CI 徽章与完整文档站，CLI 易用性打磨到位
- **协作模式**：与 Access Now 等公益组织建立成熟援助通道，是开源与 NGO 协作的长期范本

🌟 特别亮眼的地方

📖 项目是干什么的

Treg 的定位是"**工具界的 OpenRouter**"：OpenRouter 用一个接口聚合模型，Treg 用一个 base URL、一个 token 聚合工具——60+ 供应商的 3,000+ 端点，覆盖 SEO 与反链、社媒与趋势、人员与公司数据、广告、抓取、图像视频生成，按调用计费、最低一美分，无需在供应商处注册。最初为 Superdesign 团队自建，托管在 treg.to，也可自托管。

它解决的痛点是代理干真活所需的工具多藏在没人会为单次运行购买的订阅后（Semrush 139 美元/月、Moz 99 美元/月、Crunchbase 99 美元/月），或只有注册墙、无公开 API；Treg 统一持有账号、把成本摊到每次零点几美分。它也支持注册团队自有的 API key、OAuth、供应商 CLI、SKILL.md，凭证永留服务端。核心原则是**只中继、绝不建模上游，认证服务端注入**——上游怎么变都不受影响、调用方拿不到 key。凭证阶梯为：团队自有工具 → 团队存的密钥 → 免费公开路由 → Treg 账号（计费）；余额不足返回 HTTP 402 带机器可读字段。工具分 endpoint、CLI、skill/bundle 三类。

两天内 star 从 2,248 涨到 2,736（+506 今日），连续两天在榜，增长平稳。

💡 可借鉴的优点

- **产品思维**："问任务、别问工具"，用户按"我要做什么"搜索、看价、调用，把工具发现与采购的复杂度全部吃掉
- **架构设计**：忠实中继 + 服务端注入凭证是极稳的网关范式，自己不实现业务逻辑，上游变更零维护；自有密钥永远优先且不计费
- **工程化**：安装脚本→login→call 一次跑通；`treg scan` 只读预览、`treg upload` 幂等注册；Enrich Arena 横向比较各家答案、成本与速度
- **生态集成**：Claude Code 插件、Claude Connectors（读写分离给出准确安全信号）、MiniMax 插件、MCP、llms.txt，接入路径覆盖所有主流代理

🌟 特别亮眼的地方

Treg 补上了 Agent 栈长期缺失的工具统一入口与计费层：模型有 OpenRouter、执行有沙箱、编排有框架，但商业 API 调用一直没有公共网关。它把"API key 经济"改造成"按次微付费经济"，连续两天的稳定增长说明这个定位正在被采纳。

📖 项目是干什么的

Superpowers 是 Jesse Vincent（obra）和 Prime Radiant 团队做的"**编码代理完整软件开发方法论**"，构建在一组可组合技能和初始引导之上。它的核心机制从你启动代理那一刻就开始：代理一旦发现你要做东西，不会立刻写代码，而是先退一步问你真正想达成什么；通过对话把需求（spec）挤出来后，分小段展示给你确认；设计签字后，再拼出一份"清晰到没经验、没判断力、不爱测试的初级工程师也能照做"的实现计划，强调真正的红/绿 TDD、YAGNI 和 DRY；你说"开始"后，进入子代理驱动开发——派代理逐个完成工程任务、检查评审它们的产出，代理常常能照着计划自主工作一两个小时不跑偏。

它把这套方法论固化成一条自动触发的七步工作流技能链：**brainstorming**（写代码前苏格拉底式澄清需求、存设计文档）→ **using-git-worktrees**（在新分支建隔离工作区、验证干净测试基线）→ **writing-plans**（拆成 2-5 分钟的任务，每个带精确文件路径、完整代码和验证步骤）→ **subagent-driven-development / executing-plans**（每任务派新子代理并两阶段评审，或当前会话内联执行）→ **test-driven-development**（强制 RED-GREEN-REFACTOR，甚至删掉测试之前写的代码）→ **requesting-code-review**（按计划评审、严重问题阻断）→ **finishing-a-development-branch**（验证测试、给出合并/PR/保留/丢弃选项）。技能库里还有系统化调试（四阶段根因）、并行代理调度、接收代码评审、写新技能的元技能。

它最大的工程特点是**跨 harness 的全覆盖**：Claude Code、Antigravity、Codex（App/CLI）、Cursor、Devin、Factory Droid、Gemini CLI、GitHub Copilot CLI、Grok、Kimi Code、OpenCode、Pi、Qwen Code、Hermes、Muse 共 16 种代理都能装，技能自动触发。会话出问题时有 diagnosing-superpowers 技能，读取会话转录、给行级证据并打包脱敏 bug 报告。项目以 Shell 技能为主体、MIT 协议，提供企业商业支持；总 star 已超 29 万。

💡 可借鉴的优点

- **产品思维**：抓住了"代理写代码快、但流程乱、不爱测试、容易跑偏"的核心痛点，不卖能力卖"纪律"——把资深工程师的工作习惯产品化成技能
- **架构设计**：技能即流程、自动触发、强制顺序，是"用提示工程实现流程引擎"的范例；子代理驱动 + 两阶段评审（先查规格符合、再查代码质量）把质量关卡嵌进执行循环
- **工程化**：每个任务小到 2-5 分钟、带精确路径与验证步骤，计划可执行性极强；技能行为用专门的 eval 框架（superpowers-evals）测试，方法论本身也被测试守护
- **生态运营**：一套技能适配 16 种 harness、进入各家官方插件市场，最大化分发；自带诊断技能和脱敏反馈通道，把"出问题"也设计成闭环
