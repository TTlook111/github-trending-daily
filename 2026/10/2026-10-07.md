📖 项目是干什么的

rea（Reverse Engineer Anything）是一个面向逆向工程的统一 MCP，一句话讲清它的用途："**看到一个你喜欢的功能，理解它是怎么做到的，一直到二进制级别**"。它瞄准的场景非常具体：你在某个 App 里看到一个想要的功能，却拿不到它的源码——过去这意味着要么靠猜、要么得请安全专家用反汇编器啃上几天。rea 让你的 Agent 接管这件事：在无源码的情况下检查 App，解释这个功能如何工作、拿出证据，然后直接为你的项目构建一个版本。项目 2026 年 4 月创建，TypeScript 编写，采用 MIT 许可证，今天以 +2,956 一上榜就断层登顶。

它的本质是一座"**连接桥**"：把 Agent 接到一整套逆向工具上——原生二进制、JavaScript/Electron 应用、.NET 程序集、网站都能查，同一批工具也能直接在终端里用。深度原生分析时它复用你机器上已有的 **Hopper、Ghidra 或 IDA Pro**（setup 可在你批准后安装 Hopper），静态 JavaScript 分析甚至不需要任何反汇编引擎；固件区域检查调用 Binwalk/Unblob，静态 APK 分析用 headless JADX。所有分析都在本地运行、绝不上传，每个结论都附带"证据（Evidence）"和"它这次没能确定什么（limitations）"。

它把逆向过程抽象成清晰的三段模型——**Decompile（反编译，恢复可读代码、字符串、命名）→ Understand（顺着代码追踪，直到能解释功能真正的运作）→ Recreate（把学到的东西重建成适配你技术栈的功能）**。工具目录极其庞大：原生检查 41 个、调查工作流 14 个、浏览器观察 9 个、应用工作流 8 个，还有 macOS 原生工具、.NET、固件、Android、Electron 等十余个家族。架构上，Agent/终端 → REA（CLI+MCP）→ 目标绑定的会话路由器 → 深度 provider 注册表（确定性选择 Hopper/Ghidra/IDA）→ 受截止时间与清理约束的 provider 运行时，分层干净。一条 `npx rea-agents setup` 即可完成注册，支持 Claude Code、Codex、Cursor、Gemini、Windsurf、Devin、Copilot 等十余家 Agent。

💡 可借鉴的优点

- **产品思维**："看到功能→搞懂到二进制→为你重建"把高门槛的逆向工程变成一句自然语言指令；"无源码也能查 + 当场实现"打通了从洞察到代码的完整闭环，今天 +2,956 的断层热度即是市场投票
- **架构设计**："公共接口描述想了解什么、provider 决定如何回答"，接口与实现彻底解耦；深度引擎注册表做确定性选型，失败绝不静默切换工具；CLI 与 MCP 共用同一套工作流和证据契约
- **工程化**：每个结论都强制带证据与限制，不声称"恢复了原始源码"或"自动克隆 App"，诚实划清能力边界；setup 改动前先展示、自动备份配置；用快照（snapshot）在目标字节、参数、工具完全匹配时复用结果，兼顾成本与可复现
- **社区运营**：提供中英日韩阿拉伯多语言 README、doctor 诊断命令、详尽的各 provider 指南与安全策略；公开 Roadmap 与验证范围，把"哪些平台已验证、哪些还没"摊开，贡献者容易切入

🌟 特别亮眼的地方

rea 代表的是"**专家级能力 Agent 化**"最有想象力的方向之一：它不是让 Agent 写更多普通代码，而是把逆向工程这种过去需要多年功力、专用软件和极强耐心的手艺，变成 Agent 可调用的标准化能力，并严谨地保留了"证据链"这一专业底线。它与这两天的 AnyPS5（主机程序重链）、text-to-cad（Agent CAD）血脉相连，共同标志着 Agent 的触角正从软件表层深入到二进制、硬件与制造等硬核领域。👉 任何需要研究竞品实现、还原无源码 App 的行为、做安全分析或 CTF，或想学习如何把一个高门槛专业领域封装成 Agent 可调用 MCP 的开发者，rea 都是目前工程最完整、姿态最诚实的开源参考。

📖 项目是干什么的

e2e 连续第二天稳居第 2，而且热度不降反升——新增从昨天的 +1,398 升到今天的 +1,725，总 star 从 4,927 涨到 6,447，是这两天走势最强劲的项目之一。它是面向 Web 和移动应用的端到端测试框架，核心创新是把"**自然语言 Agent**"和"**确定性断言**"缝进同一条测试：你用自然语言描述目标，Agent 驱动 App 去达成，再用传统 locator 和 assertion 检查结果。项目 2026 年 7 月创建，TypeScript 编写，采用 Apache-2.0 许可证。

它最巧妙的设计是「**Agent 步骤可回放**」：一个被后续断言验证通过的 Agent 步骤，会把当时的动作记录下来；下次运行直接回放、不再调用模型，直到应用发生变化；不含 Agent 步骤的测试则完全不需要模型。这一刀精准解决了 AI 测试落地的两大障碍——成本与不确定性：只有应用变化、需要重新"探索"时才花钱调模型，平时回放既快又稳定、结果可复现。模型完全开放，可自带订阅、API key 或本地模型。

它是分层的包体系：`e2e`（SDK/runner/CLI）、`@e2e-dev/web`（经 Playwright 驱动三大浏览器）、`@e2e-dev/mobile`（驱动 iOS/Android 模拟器）、`@e2e-dev/github`（把结果作为 PR 评论发布），以及托管浏览器/模拟器的 kernel 与负责受限语义动作的 decision-model 执行器。一个贴心细节是文档随包发布，编码 Agent 能在 `node_modules/e2e/docs` 离线阅读。

💡 可借鉴的优点

- **产品思维**："自然语言驱动 + 确定性断言"兼得 AI 的灵活与测试的严谨；"验证过就回放、不重复调模型"把成本与不稳定两大痛点一并解决，连续两天高位且新增反升，说明需求真实而强烈
- **架构设计**：Agent 探索层（一次性、可替换）与动作回放层（确定性、可复现）分离；web/mobile 双引擎复用 Playwright/agent-device 成熟底层，自己专注编排与语义
- **工程化**：`npx e2e init` 交互式初始化；文档随包离线可读（专为 Agent 设计）；匿名遥测且可一键关闭；PR reporter、托管引擎等 CI/CD 配套完整
- **社区运营**：背靠 TesterArmy 商业测试平台，开源框架与商业平台形成清晰漏斗；Discord + 文档站 + 安全响应策略规范

🌟 特别亮眼的地方

e2e 给出了 AI 用于测试的"正确打开方式"：**用 AI 做需要探索和判断的部分，用确定性回放和断言做需要稳定复现的部分**。它让模型调用成为一次性投入、随后自动沉淀成确定性测试——这与软件工程"先探索、后固化"的规律高度一致。连续两天 #2 且热度反升，说明"可靠的 AI 测试"正是 Agent 走向生产时最被渴求的能力。👉 任何想用 AI 降低 e2e 编写成本、却担心结果不稳、烧钱的团队，这套"Agent + 回放 + 断言"范式都非常值得借鉴。

📖 项目是干什么的

openGym 昨天以 +1,433 登顶，今天微降到第 3，但新增几乎持平（+1,419）、总 star 从 4,312 涨到 5,812，热度并未真正消退。它是一个自托管的健身与自重训练追踪器，定位是"**你真正拥有的健身 App**"，瞄准的痛点很现实：绝大多数健身 App 把你的训练和身体数据存在它们的服务器上、不断引导订阅，一旦公司倒闭或服务关停，你几年的记录随之蒸发。openGym 跑在你自己的机器上、数据放在你控制的文件夹里，同时保持现代 App 的体验。项目 2026 年 7 月创建，采用 AGPL-3.0 许可证，一条 `docker compose up` 即可运行，无账号、无订阅、无广告、无遥测。

它的功能完整度在同类开源项目里堪称"过剩"。内置 1,324 个带动画演示的动作，可在肌肉图上按部位检索、按器械过滤，提供多套可编辑入门计划，支持超级组、热身组、递减组、休息暂停与计时有氧；训练时今日训练自动开始、上次重量自动预填、组间休息自动计时、PR 即时识别，还能根据你拥有的杠铃片自动计算配重。

最专业的是**进步追踪**：支持线性、Greyskull LP、双渐进等多种渐进规则，没完成次数绝不加重、停滞自动减载；可估算 1RM 曲线、给出结构平衡比例、配年度活动热力图；肌肉图有"容量分布 / 仍在恢复 / 已停训"三种模式。技术栈用 React + Vite 构建 PWA、Node.js 后端、Docker 部署、WebAuthn/passkeys 认证，并可从 FitNotes/Strong/Hevy 导入历史数据。

💡 可借鉴的优点

- **产品思维**："数据在别人服务器、逼你订阅、公司没了数据就没了"三连痛点极其精准；用"自托管 + 可拥有 + 现代体验"同时回应安全、成本和迁移焦虑，在线 demo 让人零门槛试用
- **架构设计**：规划 / 训练 / 进步三大模块清晰对应训练的完整生命周期；把资深教练的领域知识（渐进规则、结构平衡、恢复窗口、杠铃片数学）全部显式建模，是垂直领域知识工程化的优秀范例
- **工程化**：PWA 离线 + passkey + 跨端同步 + Docker 一键部署，兼顾自托管的可控与消费级的易用；双 CI、覆盖率、版本发布与 Changelog 一应俱全；上传前去位置信息、无遥测，隐私设计落到细节

🌟 特别亮眼的地方

在满屏"教 Agent 工作"的元层项目里，openGym 代表的是另一种同样持久的价值——**把个人健康数据彻底还给用户**。它没有靠 AI 噱头，而是把一个垂直品类的功能深度、专业严谨和数据主权做到了商业 App 都难以企及的程度。连续两天高位（+1,433、+1,419）说明这种"可拥有的好工具"需求稳定。👉 任何认真对待训练、却不愿把身体数据托付给订阅制商业 App 的人，尤其是看重自托管与数据可迁移的开发者，openGym 都是一个几乎"开箱即用、功能过剩"的选择，也是"如何把垂直领域做深、做透、做到可拥有"的上佳范本。

📖 项目是干什么的

AnyPS5 连续两天排在第 4，新增从 +997 微降到 +949、总 star 从 5,012 涨到 6,735，是今天"硬核系统工程"的稳定一极。它是一个把 PS5 可执行文件自动移植到 Linux 和 Windows 的工具，核心机制不是模拟、也不需要额外运行时进程，而包含两大组件：一个 **relinker（重链器）** 负责把 PS5 可执行文件转换成目标系统的原生格式，以及一套可用于动态链接的 **系统 prx 库实现**。它走"翻译/重链成原生程序"的路线（类似 Proton 之于 Windows 游戏，但针对 PS5）。项目 2026 年 8 月创建，C++ 编写，采用 GPL-2.0 许可证。

从项目状态能看出它的工程推进方式：系统库覆盖率以"已知函数占比"量化、随开发持续增长；**着色器重编译器**已能成功产出 SPIR-V（经 SPIRV-Tools 校验），底层图形走 Vulkan。官方验证的 2D 平台游戏《Dreaming Sarah》在 GTX 1050 Ti / i5-7500 这样的普通配置上能稳定 60 fps；对不支持或意外的状态，它直接抛出 `std::runtime_error`、打印到 stderr 并终止，绝不静默错误。

输入上支持经 SDL 映射的手柄（含摇杆和扳机），键鼠可通过 ini 配置。项目特别强调合规边界：用于互操作、研究、软件保存与兼容性目的，本身不包含、不分发也不需要任何受版权保护的软件、固件、密钥或专有库。

💡 可借鉴的优点

- **产品思维**：目标极其聚焦——"自动移植、原生运行、无需模拟"，把复杂兼容问题收敛成一条清晰技术路线；明确的免责与合规声明，既保护项目又引导用户合法使用
- **架构设计**：重链器（格式转换）+ prx 系统库（动态链接）+ 着色器重编译（PS5 着色器 → SPIR-V/Vulkan）分工明确，是"二进制翻译/原生重链"类兼容层的典型架构
- **工程化**：用覆盖率徽章量化系统库与着色器进度；SPIR-V 输出经 SPIRV-Tools 严格校验；不支持的状态一律显式抛错而非静默处理，这种"快速失败"的纪律在系统级项目里非常可贵
- **社区运营**：公开验证游戏兼容列表、输入映射文档、技术债清单和代码规范，把成熟度与短板都摊开，贡献者能快速找到切入点

🌟 特别亮眼的地方

AnyPS5 延续了开源世界最动人的传统之一——**软件保存与互操作**：通过把主机程序重链成 PC 原生程序，让游戏和软件不被锁死在特定硬件上、得以长期留存和研究。有意思的是，今天登顶的 rea 同样以 Ghidra/Hopper 二进制分析见长，两者一攻"主机程序移植"、一攻"任意程序逆向"，共同把"二进制级硬核工程"推到台前。👉 任何对二进制翻译、游戏兼容层、Vulkan/SPIR-V 着色器重编译感兴趣，或看重软件长期保存的开发者，AnyPS5 都是工程含金量很高、边界清晰的研究级项目。

📖 项目是干什么的

i-have-adhd 是一个"**阻止你的编码 Agent 埋没答案**"的技能，主打 ADHD 友好的输出方式（并特别说明：**不需要真的有 ADHD 诊断**），总 star 5.4 万，今天以 +326 排在第 10。它针对的是 Agent 一个极其常见、又特别消磨耐心的毛病：答案明明很简单，却被层层铺垫、寒暄、题外话埋在一大段文字里。项目 2026 年 5 月创建，采用 MIT 许可证。

它用一个鲜明的 Before/After 讲清价值。**Before**："好问题！让我想想。你的认证流程涉及中间件、token 校验和 cookie 处理……一个办法是更新依赖再重写那个函数，改完你可能还想跑下测试，顺便你也该看看整体依赖版本。希望对你有帮助！"——一堆废话，答案得自己捞。**After**："修改 `src/auth.ts:42` 以更新 token 校验。1. 打开该文件；2. 用下面片段替换 42–58 行；3. 运行 `npm test -- auth.spec.ts`。下一步：如果有测试失败，把第一条报错贴给我。"——行动在前、步骤编号、结尾只给一个明确的下一步。

它把这套要求浓缩成 **10 条铁律**：① 先给下一步行动；② 多步任务编号；③ 以一个具体下一步结尾；④ 抑制离题；⑤ 每轮重述当前状态；⑥ 给具体时间估算（说分钟，不说"一会儿"）；⑦ 让成果可见；⑧ 就事论事地报告错误；⑨ 列表最多 5 项；⑩ 无前言、无回顾、无结尾客套。技能松散基于《The Adult ADHD Tool Kit》一书，但改编的对象是"LLM 该如何回应"，而非真人如何安排一天。

💡 可借鉴的优点

- **产品思维**："Agent 啰嗦、埋答案"是几乎人人每天都在忍受的高频痛点，一个技能、10 条规则就给出极简解药；Before/After 对比极具传播力，价值一眼可见
- **架构设计**：不追求大而全，而是把"输出该长什么样"收敛成 10 条可判定、可执行的硬规则，单一切入点、极易记忆和落地
- **工程化**：以技能/插件形态分发，覆盖 Claude、Codex、Cursor、Gemini、Kimi、Qwen 等多家，并提供 evals、tests、hooks 来验证规则是否被遵守；可 fork 后改 SKILL.md 再替换
- **社区运营**：README 提供十余种语言版本、统一的"让 Agent 从仓库安装"指令和详尽 INSTALL/AGENTS 文档；明确标注理论出处，态度坦诚

🌟 特别亮眼的地方

i-have-adhd 是今天"**反 AI slop**"浪潮里最轻、也最锋利的一把刀：impeccable 治的是视觉上的千篇一律，它治的则是语言上的啰嗦与回避——两者都在把"专业人士如何高效沟通"从隐性习惯，变成 Agent 必须遵守的显性规则。它提醒我们，Agent 的"专业感"往往不在于说得多，而在于能否第一时间给出可执行的下一步。👉 任何受够了"好问题！希望对你有帮助！"这类废话、想让编码助手直接给行动和编号步骤的开发者，i-have-adhd 都是一个 30 秒就能装好、立刻见效的开源技能，也是"小切口、强约束"产品设计的优秀范例。

## 📊 今日趋势洞察

- **核心方向**：**「专家能力 Agent 化」，rea 把逆向工程做成 Agent 技能并断层登顶**。morluto/rea 以 +2,956（近 3000、是第二名 1.7 倍）一上榜就夺冠，它把 Hopper/Ghidra/IDA 等专业反汇编引擎统一编排，让 Agent 在无源码情况下把 App 从交互行为追踪到原生二进制、搞懂功能并当场重建，且每个结论都带证据与限制。这标志着 Agent 的触角正从写普通代码，深入到逆向、二进制等高门槛专业领域。
- **升温领域**：**「元层」大爆发——技能、规范、方法论成为新的竞争焦点**。今天 10 个项目里一大半是喂给 Agent 的技能而非终端应用：mattpocock/skills（工程基本功，+889）、impeccable（设计语言+60 条反 slop 规则，+616）、i-have-adhd（反啰嗦 10 条铁律，+326）、agency-agents（专家团队，+623）、claude-mem（跨会话记忆，+534）。它们都以 "skill" 为交付形态、经 `npx skills add` 与插件市场分发——**技能正在取代框架，成为 Agent 时代新的代码形态与分发单位**。
- **值得注意的信号**：**「反 AI slop」成为显学，工程经验被重新编码进 Agent**。impeccable 逐条点名 Inter 字体、紫蓝渐变、卡片套卡片等"一眼 AI"的设计胎记；i-have-adhd 专治"好问题！让我想想……"式的铺垫埋答案；Matt Pocock 系统总结跑偏、啰嗦、代码跑不通、滚成泥球四大失败模式。市场对 Agent 的要求正从"能用"转向"像资深工程师/设计师一样专业"。
- **对开发者的启发**：① 最值钱的机会正在从"模型能力"上移到"技能与方法论"元层，把资深人士的隐性经验做成 Agent 可执行、可判定的技能（rea、mattpocock、impeccable 都是范本）；② 学 rea/impeccable 用"确定性规则 + 证据契约"保证专业底线，能机器判定的就别全交给模型；③ 生产化继续看好"自动测试"，e2e 连续两天 #2 且新增反升（1,398→1,725），text-to-cad 也从 #10 升至 #7，持续在榜并升温是可靠的选型硬指标；④ 个人和团队可主动为 Agent 配好"记忆（claude-mem）+ 工程技能（mattpocock）+ 设计规范（impeccable）+ 输出纪律（i-have-adhd）"这套元层组合，显著提升协作质量；⑤ 硬核工程与物理制造方向（rea 逆向、AnyPS5 移植、text-to-cad 制造）连续多天升温，值得具备相关背景的开发者重点关注。
