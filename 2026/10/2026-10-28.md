📖 项目是干什么的

LinkSwift 是一个浏览器用户脚本（油猴/脚本猫），基于油小猴的【网盘直链下载助手】（syhyz1990/baiduyun）修改而来，用来获取网盘文件的下载地址，再推给 IDM、ABDM 等下载器。README 写明支持百度网盘、阿里云盘、中国移动云盘、天翼云盘、迅雷云盘、光鸭云盘、夸克网盘、UC 网盘、123 云盘九大网盘，另配有"会员青春版"系列扩展脚本。

仓库结构很简单：核心就是几个 `.user.js` 文件，加上 eslint 配置和 package.json。分正式版（v1.1.3）和金丝雀版（v1.1.4，9 月更新：新增光鸭云盘、适配 123 云盘改版、请求头标准化、用 eslint 检查代码、修复 ABDM 推送误报失败）。分发渠道是 GitHub、Gitee、脚本猫和 OpenUserJS。README 有很长一段免责声明：链接都来自网盘服务商公开的接口，**不承诺也不实现破解限速**，速度快慢取决于服务商策略和你的网络。项目由一个人维护，今天 +3,209，登顶全站。

💡 可借鉴的优点

- **产品思维**：只做一件事——"拿到直链交给你自己的下载器"，把九个网盘的差异藏在一个统一的弹窗后面。
- **工程化**：正式版 / 金丝雀版双通道，新功能先在金丝雀版跑，降低一人维护时改坏线上用户的风险；后期引入 eslint 规范脚本代码。
- **合规表达**：主动写清"用的是公开接口、不破解限速"，并点名反对"速度起飞""限速破解"之类的夸大宣传，这类灰色地带工具很需要这样划清边界。
- **社区运营**：明确"只在 GitHub 受理 Bug 反馈"、列出官方发布渠道并提醒其他来源概不负责，集中反馈、也防止被二次打包。

🌟 特别亮眼的地方

在一张几乎被 AI Agent 占满的榜单上，一个"老派"用户脚本拿下当日第一，提醒我们：**真实、高频、本地化的刚需永远有流量**，而且中文用户的集中爆发可以单日把一个项目推到榜首。👉 做工具的开发者：它的"统一适配层 + 双发布通道 + 清晰免责边界"是维护多平台适配类小工具的很好样板；同时也要注意，这类依赖第三方接口的工具随时可能因对方改版失效，适配速度就是生命线。

📖 项目是干什么的

hallmark 是 Together AI 出品、给 Claude Code、Cursor、Codex 等编码 Agent 用的"反 AI slop"设计技能。它把 AI 生成界面里最常见的"机器味"列成反模式清单（标题上的小眉标、全大写宽字距标签、只染一个彩色词的标题、每页都塞邮件订阅、表单"谢谢"了却没发出去等），然后在真实浏览器里对结果做检查。

v2 的核心是 48 套"材质"主题：每套不超过 8 KB，只规定纸张、字体、色彩、表面质感，不规定页面结构——结构从用户要完成的任务推导。流程是先读项目、只问一次要真实素材（不编造）、给三个候选主题、首屏单独冷启动评审、8 个宽度检查，最后交给新上下文的子代理复审；检查分 Floor（永不放行，包括编造事实）、Reflex（可有理由推翻）、Finish（不阻塞发布）三层。今天 +2,830，连续三天加速（+1,317 → +2,244 → +2,830）。

💡 可借鉴的优点

- **产品思维**：把"AI 塑料感"这种模糊感受拆成具体可检查的条目，用户一看就懂、一用就能对照。
- **架构设计**：主题管"材质"不管"结构"，避免同一模板生成千篇一律的页面。
- **工程化**：分层门禁 + 多宽度浏览器检查 + 新上下文复审，把审美变成可重复的质量流程。
- **社区运营**：每套主题都有成品图、集中展示，视觉项目用视觉传播。

🌟 特别亮眼的地方

hallmark 连续加速，说明开发者已经不满足于"Agent 能写出能跑的界面"，而是要求"别人看不出是 AI 做的"。它把"不编造事实"放进最高一级门禁，审美约束顺便成了诚实约束。👉 做生成式 UI 的团队：今天榜上有 4 个设计技能，hallmark 的分层门禁是其中最容易照搬到自家流程里的一套。

📖 项目是干什么的

VoiceStudio 是一个开源、完全本地运行的语音 AI 工具箱，直接对标 ElevenLabs：语音克隆、音色设计、按时间轴给视频配音、听写与转写、故事/有声书/批量任务，都集中在一个桌面应用里，宣称覆盖 646 种语言。功能按 **Create**（克隆/设计音色、浮窗听写）、**Produce**（视频配音、有声书与批量生产）、**Connect**（本地 API、给 Agent 用的 MCP、可复用 recipe 与监听文件夹）三栏组织。

默认引擎基于 k2-fsa/OmniVoice，也可替换为其他引擎；OmniVoice 的 GGUF 构建在 Windows/Linux 上可选 Vulkan 加速，没有显卡也能退回 CPU。项目强调本地工作流跑在自己的硬件上、远程服务可选、使用统计需用户同意。安装是一条命令（macOS/Linux 用 curl，Windows 用 PowerShell `irm | iex`），带 SHA-256 校验，升级保留设置、项目和模型。今天 +2,621，比昨天（+2,297）更快，总 star 逼近 9.2 万。

💡 可借鉴的优点

- **产品思维**：用"开源 + 完全本地 + 对标 ElevenLabs"一句话占住心智，切中对声音数据隐私敏感、又不想按量付费的创作者。
- **架构设计**：引擎可插拔，应用层和模型层解耦，后续换更强的 TTS/克隆模型不必重写产品。
- **工程化**：一键安装带校验、升级不丢数据、GPU 加速可选并自动回退 CPU，把"本地 AI 应用难装难升级"处理得很干净。
- **生态衔接**：自带本地 API 和 MCP，让语音能力直接成为 Agent 的工具，而不只是给人点的 GUI。

🌟 特别亮眼的地方

VoiceStudio 已经连续多天处在全站前三，在设计技能和编码 Agent 扎堆的榜单上独占"多模态内容生产"这条线，说明**本地化、去订阅化的 AIGC 工具**是一条独立且持续的强需求。它默认把自己做成 Agent 可调用的 MCP 工具，也代表了本地 AI 应用的新常态。👉 做本地 AI 桌面应用的开发者："可插拔引擎 + 一键安装带校验 + MCP 接口"这三件套可以直接参考。

impeccable 自称"让你的 AI harness 更懂设计的设计语言"：1 个技能、24 条命令、浏览器内实时迭代，加上 62 条确定性检测规则。它从 Anthropic 官方的 frontend-design 技能出发，专门针对模型的通病——满屏 Inter、紫蓝渐变、卡片套卡片、彩色背景上的灰字等。

💡 可借鉴的优点

- **架构设计**：LLM 做主观评审、确定性规则做客观检测，成本和可靠性兼顾。

- **社区运营**：坦诚标注来源，建立信任。

🌟 特别亮眼的地方

📖 项目是干什么的

Huashu Design（花叔出品）的口号是"打字。回车。一份能交付的设计。"——在 Agent 里打一句话，拿回网页、可点击的 App 原型、可编辑的 PPTX、动画或信息图，号称 3 到 30 分钟就能交付。它是 HTML 原生的设计技能，`npx skills add alchaincyf/huashu-design` 安装，Claude Code、Cursor、Codex、OpenClaw、Hermes 都能用。

3.0 的核心机制：先出**六张缩略图**再挑三个方向做成真稿；风格库扩到 **84 种**（新增 App、中文与东亚分区），每种都有样张；动手前先用 `ref_board.py` 把参照作品截图成参考板；带一个"只量事实"的**设计体检**（例如发现两版首屏撞了同一张图就换掉），和一本记住你做过什么样子的**外观账本**（发现最近 6 个交付 5 个是无衬线标题，这次就挑宋体）。README 里的案例都标明素材来自开放馆藏、Wikimedia 等真实来源。仓库包含 references/、assets/、scripts/、demos/ 四个子目录，README 特意提醒旧版 skills CLI（≤1.5.15）只会同步 SKILL.md 单文件。自 2026-05-14 起改为 MIT 协议。今天 +1,214。

💡 可借鉴的优点

- **产品思维**：目标不是"AI 做的还行"，而是"能交付"，覆盖网页 / 原型 / PPT / 动画多种交付物，直接对应真实工作。
- **架构设计**：外观账本 + 设计体检，让 Agent 记得"自己做过什么"，主动避免项目之间长得一样——这是解决 AI 同质化的一个很巧的思路。
- **工程化**：技能不只是一个 prompt 文件，而是带配方、脚本、素材的完整包，并主动排查安装工具的版本 bug。
- **社区运营**：中文作者亲录教程、README 本身全由技能生成，作品即广告；从商用授权改为 MIT 也打开了企业使用场景。

🌟 特别亮眼的地方

huashu-design 是今天设计技能里**中文和东亚审美**最突出的一个（宋体、书籍设计、民国书衣等参照），说明"反 AI 塑料感"在不同文化语境里会长出不同答案。"外观账本"把同质化问题从单次生成上升到跨项目记忆。👉 做生成式设计的团队：记录历史产出、主动做差异化，比在单次 prompt 里要求"要有创意"可靠得多。
