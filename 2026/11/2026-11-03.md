| 属性 | 信息 |

| 📦 分类 | AI Agent / 桌面 Computer Use CLI |

📖 项目是干什么的

agent-desktop 是 Vercel Labs 出品的「桌面版 Computer Use」CLI 和 C 库，支持 macOS、Windows、Linux。它不靠截图和像素匹配，而是读取操作系统的**无障碍树（Accessibility Tree，Linux 上用 AT-SPI）**：`snapshot` 返回 JSON，每个可操作元素带一个 ref；Agent 对 ref 执行 `click`、`type`、`set-value` 等动作，再 snapshot 一次验证结果，循环逻辑留在 Agent 侧。

共 60 个命令名（56 个可用），覆盖观察、按 ref 操作、键鼠、应用与窗口、通知、剪贴板等。每次调用都是独立进程，默认禁止抢焦点和合成输入，需要物理输入时显式加全局开关；每条输出都是带 `ok` / `error` 的 JSON 信封，错误里带 `disposition.retry` 告诉 Agent 能否安全重试。还附带 `libagent_desktop_ffi`，可以在进程内直接调用。今天 +2,275，总 star 约 9,700，是今日增速第二。

💡 可借鉴的优点

- **架构设计**：用无障碍树代替视觉识别，结果确定、可复现，成本远低于截图 + 多模态模型。
- **工程化**：「快照 → 按 ref 操作 → 再快照验证」的协议清晰；UI 变化时旧 ref 直接报错，逼 Agent 重新观察而不是盲点。
- **产品思维**：错误码带「能否重试」的处置建议，是专门为 Agent 而非人类设计的 CLI 输出。
- **社区运营**：二进制自带与版本匹配的 skill 文档（`agent-desktop skills get desktop`），可一行装进各家 Agent。

🌟 特别亮眼的地方

它和同门的 agent-browser（浏览器自动化 CLI，约 4.5 万 star）组成一套「**给 Agent 用的操作系统接口**」。👉 做 Agent 工具：优先用结构化接口（无障碍树、DOM、API）而不是像素，并把输出设计成机器可判断的 JSON 信封。

## 📊 今日趋势洞察

### 核心方向

1. **Agent 操作电脑**：agent-desktop 用无障碍树而不是截图来操作桌面应用，结构化接口正在取代像素级的 Computer Use。
2. **Agent 外壳与记忆**：t3code 连续登顶、claude-mem 增速继续上升，开发者关注点从「用哪个模型」转向「怎么用好已有的 Agent」。
3. **配置即产品**：mattpocock/skills、ECC、superpowers（+647）三个约 30 万 star 的技能/配置仓库同日在榜。

### 升温领域

1. **本地语音输入**：hex 与 Handy 同日上涨，语音成为给 Agent 下指令的新入口。
2. **沙箱执行的聊天 Agent**：OpenMausBot、Codync 都以「开源 Grok Bot 替代」为卖点。
3. **领域基础模型**：Kronos 把语言模型的预训练范式搬到 K 线时间序列。

### 对开发者的启发

- **做 Agent 工具**：优先提供结构化接口（无障碍树、DOM、API），输出设计成带错误码和「能否重试」提示的 JSON。
- **做 Agent 产品**：外壳、记忆、语音输入是最近最热的三个切入点，都不需要自己训练模型。
- **团队落地**：把好用的技能和配置做成仓库版本化共享；Agent 的执行动作放进隔离环境。
- **一个贯穿的共性**：今天的热门项目大多在**模型之外补齐 Agent 的感知、操作、记忆和输入方式**。
